### 🔬 Open-Source Projects

**[EVPIX-RV32: Custom RISC-V SoC with IPU & TinyML Accelerator](https://github.com/aukhalid/evpix_rv32)** - My flagship project. A 32-bit, 5-stage pipelined RISC-V (RV32I) processor integrated with an Image Processing Unit (IPU) and TinyML Accelerator for real-time edge-vision AI.
- Verified via real **Basys-3 AMD Artix-7 FPGA** prototyping.
- Completed full **RTL-to-GDSII ASIC flow** using **OpenROAD Flow Scripts** with **SkyWater 130-nm PDK**.

**[APB Peripheral Subsystem & UVM Verification Suite](https://github.com/aukhalid/apb-peripheral-suite)** - APB3/4 subsystem integrating UART, SPI, I2C, GPIO, Timers, PWM, WDT, and a Memory Controller with a full modular UVM environment, SVA assertions, and Makefile regression automation.

**[Common IP Library with OOP Testbenches & SVA](https://github.com/aukhalid/sv-common-ip-library)** - Parameterizable SystemVerilog IP library (RAMs, FIFOs, CDC Synchronizers, Arbiters) with class-based layered testbenches, bind-module SVA, and a two-tier Makefile build system.

**[CMOS VLSI Logic Designs — GPDK90](https://github.com/aukhalid/CMOS-VLSI-Logic-Designs-gpdk90)** - Custom CMOS standard cells and digital subsystems in 90-nm GPDK. Full transistor-level schematics, layout, pre/post-layout simulation, DRC, and LVS.

**[SAP-1 CPU in Logisim](https://github.com/aukhalid/SAP-1-CPU-Logisim)** - Functional simulation of the Simple-As-Possible CPU with a hardwired Control Unit, system ROM, and custom bootloader for RAM initialization.
